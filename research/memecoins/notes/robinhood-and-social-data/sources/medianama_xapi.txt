TITLE: X API Pricing: $0.005 Per Post Under New Pay-Per-Use Model

X API Pricing: $0.005 Per Post Under New Pay-Per-Use Model Skip to content × Search for: X has launched a new pay-per-use pricing model for its developer application programming interface (API), replacing the earlier pricing model that required developers to pay fixed monthly fees of up to $200 or $5,000. The company says developers will now be charged based on API requests made to access data or perform platform operations, with no monthly subscription or usage caps. The API provides access to public posts, users, trends, direct messages, and other platform features through what X describes as real-time tracking. For example, reading a post costs $0.005 per post, accessing user profile data costs $0.010 per user, and creating a post costs $0.010 per request as well. X’s own pricing example shows that moderate monthly usage across reading posts, users, and direct messages could cost around $215 per month. However, while the pricing structure lowers the entry barrier, costs can still rise quickly with higher usage. The Elon Musk-owned platform says the change is aimed at independent developers, early-stage startups, and hobbyists. X had faced widespread criticism in 2023 after introducing high fixed API fees, which led to the shutdown of several bots, research tools, and third-party applications that relied on the platform’s data. Alongside the pricing change, X has also introduced a redesigned developer console that allows developers to create apps, purchase credits, and monitor API usage in real time. xAI integration and Grok’s expanding availability X has also linked the API pricing update to its artificial intelligence arm, xAI, by introducing a tiered, credit-based incentive that connects spending on the X API with access to xAI’s models. Under this scheme, developers who purchase X API credits can earn xAI API credits worth up to 20% of their cumulative spend within a billing cycle, depending on how much they spend overall. According to X’s developer documentation, the incentive is structured around spending thresholds. Developers receive no xAI credits for cumulative spend below $200 in a billing cycle. However, once total spending reaches $200, they receive xAI credits equal to 10% of their entire cumulative spend. This rate increases to 15% once cumulative spend crosses $500, and to 20% when spending exceeds $1,000 in a single billing cycle. The credits are calculated on a rolling basis: as developers cross each threshold, they receive only the additional amount owed, rather than the full percentage again. For example, a developer who spends $1,000 on X API credits over the course of a billing cycle would ultimately receive $200 worth of xAI API credits, regardless of whether that spend happens in one transaction or several smaller purchases. Previously, xAI had launched an API for Grok in October 2024, offering access to a single model, “grok-beta”, with usage-based pricing tied to input and output tokens. At the time, the documentation described the API as limited in scope and indicated support for features such as function calling, along with references to future vision models. Why this matters The structure of the new pricing and incentives points to a broader shift in how X is positioning its developer ecosystem. First, the pay-per-use model lowers the cost of accessing X’s data, making it easier for developers to build applications that rely on public posts, trends, and real-time conversation. This follows a period in which many developers stopped building on X after high fixed fees were introduced. Second, the bundling of xAI API credits with X API spending links the use of X’s data directly to Grok and other xAI tools. X financially nudges developers who work with its data to also experiment with Grok, keeping application development within the combined X–xAI stack rather than external AI platforms. Third, the move creates a clearer path to monetising X’s data. Instead of flat subscriptions, developers now pay in proportion to how much data they read or actions they perform, turning access to real-time social media data into a metered revenue stream. At an industry level, the change could make X’s data more attractive for building AI-driven tools, including analysis, monitoring, and generative applications that depend on live social content. It also places xAI and Grok more directly in competition with established AI platforms such as OpenAI, Google, Anthropic, and Meta by tying AI usage to a large, proprietary data source.
